# Dify Enterprise Helm Chart for SUSE Rancher

This repository publishes a Rancher-friendly Helm chart for Dify Enterprise
3.11.1. The chart includes a guided `questions.yaml` form for Rancher,
bilingual field descriptions, validation rules, and defaults based on a
validated SUSE Rancher deployment.

## Add to Rancher

In the target cluster, open:

`Apps` → `Repositories` → `Create`

Use these values:

- Name: `dify-suse`
- Target: `http(s) URL to an index generated by Helm`
- Index URL:
  `https://raw.githubusercontent.com/DuDuDuMaxVerstappen30/dify-suse-helm/main/index.yaml`

Wait for the repository to become `Active`, then open `Apps` → `Charts` and
search for **Dify Enterprise**.

## Command-line installation

```bash
helm repo add dify-suse \
  https://raw.githubusercontent.com/DuDuDuMaxVerstappen30/dify-suse-helm/main
helm repo update
helm install dify dify-suse/dify --version 3.11.1-suse \
  --namespace dify --create-namespace
```

Use Rancher's installation form or a private values file to provide all
required secrets. Do not commit passwords, licenses, registry credentials, or
production values to this public repository.

## Notes

- Default ingress controller: Traefik
- Default bundled services: PostgreSQL, Redis, and Qdrant
- Default persistence example: `local-path`, `ReadWriteOnce`
- Required secrets are intentionally not included

This package is intended for authorized Dify Enterprise deployments. Users
remain responsible for Dify licensing and image-registry access.
